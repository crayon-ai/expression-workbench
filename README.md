# 表达训练工作台

一个可以点完的界面 Demo。现在只做了「简单复述」：选一篇短材料，讲给小黄鸭听，然后看逐字稿和它作为听众的反馈。可以再讲一遍，把两遍放在一起看。

「复杂表达」在工作台上能看见，还不能进入。

没有登录，没有后端，没有真实的语音识别，也没有模型。麦克风如果允许，会真的录下声音，供后面播放；逐字稿和反馈仍是写好的示例，页面上标着「示例逐字稿」和「示例反馈」。

## 怎么打开

构建结果在 `dist/`。在这个目录里起一个静态服务即可：

```bash
cd dist
python3 -m http.server 4731
```

然后打开 <http://127.0.0.1:4731>。

也可以：

```bash
npx serve dist -l 4731
```

改界面时：

```bash
npm install
npm run dev
```

开发服务同样在 <http://127.0.0.1:4731>。改完后执行 `npm run build`，再提交 `dist/`。

## 建议点一遍

1. 工作台首页。进入「简单复述」。「复杂表达」是灰的。
2. 选一篇材料。三篇都可以，反馈会跟着材料走。
3. 读完材料，点「开始复述」。
4. 材料会收起来。鸭子在中间听。点「再看一眼材料」可以暂时看原文。
5. 点「开始讲」录音，再点「讲完了」。如果浏览器不给麦克风，仍点「讲完了」，用示例逐字稿继续。
6. 先看逐字稿。有录音可以播放。点某一句，可以改掉明显的识别错误。
7. 点「看看小黄鸭听到了什么」，再看示例反馈。反馈会指向具体的一句。
8. 「再讲一遍」回到鸭子。不会自动开始第二次录音。
9. 再点「讲完了」，两遍逐字稿并排（窄屏上下叠），并说明上一遍的问题有没有跟上。
10. 「结束这次练习」，然后可以回到工作台，或再看那两段逐字稿。

窄屏和宽屏是同一条路径。手机宽度下：先读材料，讲的时候鸭子居中，讲完后先是大段逐字稿，反馈在下面。

## 什么是假的

- 逐字稿不是刚才那段录音识别出来的。
- 反馈不会根据你改过的字重算。改过之后，页面会说明这一点。
- 鸭子不会插话，也不会打分。
