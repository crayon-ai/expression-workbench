# 表达训练工作台

「简单复述」的可用版本：选一篇短材料，讲给小黄鸭听，录音会真的转成逐字稿，反馈和复述报告由后端的模型给出。可以再讲一遍，把两遍放在一起对照。「复杂表达」在工作台上能看见，还不能进入。

## 后端

转写、反馈、报告走 `suntao-expression-api`（Cloudflare Worker），接口见 `worker/README.md`。默认地址：

```
https://suntao-expression-api.suntao-preview.workers.dev
```

可用环境变量 `VITE_API_BASE` 覆盖（本地调试 Worker 时）：

```bash
VITE_API_BASE=http://127.0.0.1:8787 npm run dev
```

进入「简单复述」选材料页时需要输入访问口令，前端调 `POST /check` 校验，通过后只存在这个标签页的 sessionStorage（key：`expression-workbench.access-code`），不进代码、不进构建产物。口令错了会提示「口令不对」，可以重输；页面上有「换一个口令」的入口。

## 隐私

录音会经我们的服务器发给智谱做语音转写，转完不保存；逐字稿只留在页面里（刷新就没有）。后端也不存录音、不存逐字稿。没有麦克风或转写失败时，会改成手动输入逐字稿，页面会写明这一点。

## 怎么打开

```bash
npm install
npm run dev
```

开发服务在 <http://127.0.0.1:4731>。构建：

```bash
npm run build
```

构建结果在 `dist/`，静态托管即可（资源用相对路径，hash 路由，不需要服务端配合）。

## 建议点一遍

1. 工作台首页。进入「简单复述」，先输入访问口令。
2. 选一篇材料，读完点「开始复述」。
3. 试音（声波一动就说明收到了），点「开始讲」，讲完点「讲完了」。
4. 「小黄鸭正在回想你说的话…」是转写进行中；录音超过 25 秒会分段转写，会显示「第 n / N 段」。
5. 逐字稿页显示真实识别的全文，按句子切开。点某一句可以改掉识别错误。录音可以播放。转写没成功时会改成手动输入。
6. 点「看看小黄鸭听到了什么」，等小黄鸭想完，看反馈：哪里听懂了、哪里没跟上（引用可以点，会滚到那一句），然后揭开前提清单。
7. 「再讲一遍」讲第二遍。两遍逐字稿并排（窄屏上下叠），对照页里小黄鸭说哪里跟上了、哪里还是没跟上。
8. 想看评分就从反馈/对照页点「获取复述报告」：材料匹配度、逻辑完整性、语言流畅度，第二遍会和第一遍对比。

## 状态说明

两遍的录音、逐字稿、反馈、报告都放在页面内存里，刷新就没有，这是有意的。反馈按（材料，第几遍，逐字稿全文）缓存在内存里，改过逐字稿后会给「让小黄鸭重新听」的按钮，不会自动重算。
